# monitoring namespace notes

k3s ships metrics-server by default, so it is deliberately not installed here — `kubectl top` and HPA metrics work out of the box. Two secrets in the `monitoring` namespace are bootstrap-provided, not managed by these manifests (see PLACEHOLDERS.md): `grafana-admin` (keys `admin-user`/`admin-password`, consumed by the Grafana HelmRelease) and `objectstore-loki` (keys `ACCESS_KEY_ID`/`ACCESS_SECRET_KEY`, Linode Object Storage credentials injected into Loki as AWS env vars). The Loki values reference the `${cluster_obj_host}`/`${cluster_obj_bucket}` object-storage vars, which Flux substitutes from the `fm-cluster-vars` ConfigMap (flux-system) at reconcile — so the real host/bucket stay out of this public repo.
